# HOUYI Antibacterial Design Atlas

Static web resource accompanying the HOUYI manuscript.

- `index.html` — overview
- `browse.html` — species browser
- `methods.html` — pipeline and limitations
- `download.html` — data tables and sequences
- `en/` — English mirror

All designs are computational predictions; no wet-lab validation is included.
